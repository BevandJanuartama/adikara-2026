# Repositori Proyek Adikara 2026: KriyaPKK

Repositori ini memuat seluruh materi kompetisi Adikara 2026 untuk ide produk **KriyaPKK** (Ekosistem Digital Pengelolaan Sampah Anorganik & Ekonomi Kreatif Berbasis AI untuk Kelompok PKK).

---

## 📁 Struktur Direktori

```text

│

│   ├── GuideBook Adikara 2026.pdf          # PDF resmi guidebook dari panitia
│   ├── GuideBook_Adikara_2026.md           # Konversi markdown isi guidebook
│   ├── PANDUAN_LENGKAP_ADIKARA_2026.md     # Ringkasan terstruktur aturan lomba

│
└── kriyapkk/                                # Dokumen proyek & rekayasa produk KriyaPKK
    ├── KRIYAPKK_PROPOSAL_LENGKAP_ADIKARA_2026.md # Naskah proposal lengkap lomba
    │
    ├── konsep_dan_alur/                    # Arsitektur sistem & alur kerja operasional
```
